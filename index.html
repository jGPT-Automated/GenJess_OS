The Crew

Scout

Prospect Sourcing

Google Maps + Exa sweep across target verticals and neighborhoods. Franchise/corporate DQ filter applied before scoring.

Cartographer

Site & AEO Audit

Live URL fetch, JSON-LD validity, llms.txt + AI-crawler allowlist, mobile/desktop screenshots, WCAG AA pass.

Forge

Spec Build

Clone vertical master template, swap brand tokens, slot AI wedge (Style Consult / Pest-ID / Yard Quote). No free-coding.

Sentinel

Independent Audit

Pass/fail on every build: 375/768/1440 viewports, computed-style contrast, JSON-LD, tap targets. Blocks outreach until clean.

Pitcher

Cold Outreach Drafter

Every claim maps to intel-pack fact. No ranking promises. Non-affiliation banner + 7-day clock language. ≤180 words.

Mirror

Reply & Follow-Up

Day-5 nudge, Day-7 takedown notice. Recycle template to adjacent neighborhood when no reply.

Foreman

Orchestrator

Maintains pipeline Sheet, sequences gates, surfaces blockers to operator. Phase-gated dispatch.

Architecture Decisions

Public / Private Split

Landing page + /skills directory are fully public. Dashboard / leads / runs / agents / settings require Clerk auth.

Dual Theme

Landing uses data-theme="dark" (black bg, #EA580C accent) — applied per-page. Dashboard uses warm light theme (#f0eeeb / #fafaf8).

Codegen Pipeline

Source of truth → OpenAPI YAML. Orval generates Zod schemas + React Query hooks. One contract, zero hand-written client code.

Skill-Driven Agents

Every agent loads a SKILL.md file as its operating manual. Skills are versioned, audited, and reused across the crew.

Everything required to pass App Store Review. Missing any of these = rejection on first submit.
Shared

Guideline 5.1.1v — Hard Reject: Apps that collect user data MUST provide in-app account deletion. Apple will reject without it, no exceptions since June 2022.

Both Apps (Non-Negotiable for Review)
In-app account deletion flow — Settings → Delete Account → confirmation modal → API call to delete user + all associated data. Must be in the app UI, not just a web form. (Guideline 5.1.1v)

P3
Revenue Architecture
Design monetization before writing IAP code. RevenueCat is the layer — it handles entitlements, receipt validation, and analytics across iOS/Android.
Shared Revenue

Apple's 30% rule: All in-app digital purchases on iOS must go through StoreKit. RevenueCat sits on top of StoreKit and gives you a single SDK, cross-platform entitlement sync, and dashboard analytics. Free up to $2.5K MRR.

Setup
Create RevenueCat project at app.revenuecat.com. Add both apps. Free tier covers up to $2.5K MRR — upgrade to Starter ($99/mo) when you cross $2.5K.
Shared
Create IAP products in App Store Connect first (status must be "Ready to Submit" before you can test). Then sync product IDs to RevenueCat dashboard.
Human
Install SDK: npx expo install react-native-purchases. Configure with Purchases.configure({apiKey: REVENUECAT_API_KEY}) at app root.
Agent

EAS Build + CI/CD Pipeline
After first manual setup, agents own the build pipeline completely. Push to main → TestFlight. Zero manual steps.
Agent-Owned
One-Time Setup (Human + Agent)
Install EAS CLI: npm install -g eas-cli. Login: eas login. Initialize: eas build:configure — generates eas.json.
Human
Configure eas.json with production (App Store distribution) and preview (simulator) profiles. Set autoIncrement: true for build numbers.
Agent
Add GitHub secrets: EXPO_TOKEN (from expo.dev account) + EXPO_APPLE_APP_SPECIFIC_PASSWORD. These are injected into CI — never commit to repo.
Human
GitHub Actions Workflow (Agent-Owned)
Create .github/workflows/eas-build-submit.yml: trigger on push to main, runs eas build --platform ios --non-interactive then eas submit --platform ios --non-interactive. Auto-uploads to TestFlight.
Agent
Pin GitHub Actions runner to macos-15 — macos-26 broke fastlane match in April 2026. Example: runs-on: macos-15.
Agent
Definition of Done
  • Merge to main → GitHub Action triggers automatically
  • EAS build completes without manual intervention
  • Build appears in App Store Connect → TestFlight within ~20–30 minutes of merge
  • Build number auto-increments on every push
